# 参考站内容清单

范围：从 `https://www.slashx.cn/c/learn` 能走到的栏目，加上站点地图和顶栏、页脚带出的页面。记录的是结构、字段和跳转，不是可复用的正文。未登录、未提交表单。应用内页在脚本运行后进入登录；下列「服务端可见」指关闭脚本或阅读 HTML 时能看到的区块。

接口 `GET /api/courses/map` 在未登录时返回 200。章节字段：`id`、`title`、`description`、`coverUrl`、`rarity`、`rarityLabel`、`courseCount`、完成与解锁计数、`courses[]`。单课字段：`id`、`title`、`description`、`coverUrl`、`durationSec`、`contentKind`（`video` / `interactive_guide` / 图文）、`priceCredits`、`accessDays`、`requiresPrev`、`inviteRedemptionEnabled`、`hasUnlocked`、`canWatch`、`checkinCount`、`checkinAvatars`。当时共 6 个章节、约 46 节。

## `/c/learn` 学习

- 地址会在客户端变成 `/login?callbackUrl=/c/learn`。
- 服务端壳：左栏图标（见 sitemap）+ 共学正文。
- 眉题、两行主标题、一段说明。
- 按钮「登录开始学习」；链接「查看课程路线」→ `#course-learning-path`。
- 三张路径：内容与设计 / 办公与运营 / 开发与创业，各有一行说明。
- 路径区：「列表」「平铺」两个按钮，控制 `#course-chapters`。说明句指向章节、练习和活动。
- 课表由 `/api/courses/map` 填入（公开 `/courses` 上能看到完整渲染，字段见下）。
- 收束标题与说明，链接「回到课程目录」→ 同一锚点。
- 资源链接：学习路径 `/learn`、会员权益 `/membership`、实战培训 `/workshops`、实操文章 `/articles`。

## `/courses` 线上学习

与上页同一英雄区和路径区，并直接渲染课表、会员卡和打卡榜。顶栏为营销导航。

章节（按出现顺序）与卡片字段：

1. 活动型章节：标签、简介、一节互动课（序号、类型标签、标题、简介、积分、未解锁、邀请码兑换）、嵌在章节里的活动条。
2. 入门章节：多节视频行。行上有封面时长、序号、标题、打卡人数与头像、免费标记、播放。章末讲师（姓名、头衔）链到 `/instructors/:slug`。
3. 之后还有接待示范、助手类、概念课、流程课。付费行显示积分而不是「免费」。概念课里有一节讨论词元（Token）的加更，仍是普通课时，不是独立的代理产品页。

活动条字段：起止时间、状态（报名中 / 即将开放）、价格、标题、地点、剩余席位、进度条、封面。链接 `/events/:id?from=/courses`。

课行链接 `/courses/:id`。页内还有会员双卡（基础 / 超级：价格、天数、权益、登录开通、分享、咨询）和邀请榜（名次、头像、昵称、分数）。

## `/courses/:id` 与 `/c/learn/:id`

- 公开详情可打开。工作台内同课未登录会去登录。
- 左栏「课程地图」：返回、章节名、每节序号与标题，当前节高亮。点击其他节仍在详情路由。
- 右上：类型、标题、简介、时长、「登录后观看」→ 登录并带回本课、「浏览更多课程」。
- 右下：同一标题和简介，以及「分享赢积分」。

## `/learn` 学习路径

和 `/c/learn` 不是同一页。

- 眉题、主标题、说明。
- 「查看已开放课程」→ `#published-courses`；「了解会员权益」→ `/membership`。
- 三张方法卡：理解能力、围着任务练工具（链到 `/articles?topic=tutorial`）、带着问题去实战（链到 `/workshops`）。
- 「目前开放的课程」按章节列出课名、类型、时长，链到 `/courses/:id` 或个别文章 `/articles/:slug`。
- 「进入课程地图」→ `/courses`。

## `/` 首页

- 眉题、品牌行、大标题、一句说明。
- 三个按钮：加入会员 `#pricing`、线上课程 `/courses`、线下活动 `/events`。
- 主视觉和两侧短句，下面三格数字与合作标识。
- 「社区新鲜事」卡片类型：活动、课程、文章，各自链到详情。筛选按钮：全部、活动、课程、文章。
- 会员六项权益、供给预览、讲师轮播（`/instructors/:slug`）、价格卡。

## `/articles` 教程与文章

- 眉题、标题、两句说明、插画。
- 搜索框 +「搜索」。筛选：全部文章、图文教程、活动介绍、关于我们。右侧篇数。
- 卡片：分类、标题、摘要、标签、作者、日期、阅读分钟、浏览数。第一张是「课程资源库」推广，链到学习。
- 「加载更多」→ `/articles?page=1`。
- 图文教程就是这一页的筛选，不是另一个域名。

## `/articles/:slug`

标题、分类、作者与时间、正文。返回列表。

## `/events` 与详情

- 眉题、大标题、插画。
- 五格计数：全部、待开始、进行中、已结束、已取消。
- 「正在进行与即将开始」「往期活动」。卡片：日、起止、状态、价格、标题、地点、剩余席位、封面。链到 `/events/:id?from=/events`。
- 详情：返回、分享、复制地址、复制联系方式、状态按钮（例如报名即将开放）。锚点：活动介绍、如何参加、取消规则。讲师链到讲师页。

## `/workshops`

标题与说明，「查看活动安排」→ `/events`，「先从线上课程开始」→ `/courses`。近期场次链到活动详情。FAQ 三问。页脚同上。

## `/solutions` 与详情

- 眉题、标题、说明、「了解超级会员」。
- 三条信任短句。搜索。筛选：全部类型、产品、服务、解决方案。排序「更多筛选」。数量。
- 卡片：类型、标题、摘要、市场价、会员价、周期。链到 `/solutions/:slug`。
- 详情分区：为什么入选、适合谁、解决什么、核心能力、价格对照、办理与兑换（外链商店兑换页和官方说明）、交付、来源边界。按钮「查看会员专属价」「咨询」。

## `/membership` 与 `/pricing`

会员页：标题、查看方案 `#join`、先看学习 `/learn`、两张价格卡、六项权益、供给条、FAQ。卡上链到 `/profile/redeem`、`/profile/membership`、团购 `/group-buys/:id`。

价格页在会员双卡之下还有四档平台方案（免费 / 个人 / 团队 / 企业）：价格、周期、要点、按钮（免费开始→登录，升级→会员锚点，顾问→外部预约）。对比表和 FAQ。

## `/login`

全屏背景上的卡片。标题「登录或注册」。按钮：微信、电子邮件、账号密码。手机区号、号码、验证码、「获取验证码」、协议勾选（协议页与隐私页）、「继续」。不提交。

## 其余营销页

- `/about`：标题、任务说明、邮箱、企业与协议链接。
- `/demands`：标题、审核中的空态或列表、「发布需求」→ 登录并带回 `?publish=1`。搜索筛选。
- `/skills`：标题、CLI / Skill / MCP / 脚手架四块、下载与文档链接、复制命令、客户端切换、登录与企业演示。
- `/platform`：白标工作台说明、四类后端、创作画布、部署与计费、终端、角色。按钮到 `/c`、`/demands`、`/extension`、`/c/studio`、`/developers`。
- `/enterprise`：标题、选场景 / 接系统 / 验收、四段卡住的状态、过程锚点、预约外链。
- `/extension`：标题、下载、五步安装、试用网页版 `/c`。
- `/developers`：长文档。概览、七类服务商、协议与 PAT。密钥说明明确不应出现在公开链接里。
- `/instructors/:slug`：姓名、头衔、简介。
- `/group-buys/:id`：团购价、人数、倒计时。

## 外链商店 `slashx.shop`

顶栏「Codex订阅」。页内：套餐、购买流程、常见问题、售后、自助兑换 `/redeem`。卡片有本站价、官方参考价、差额和功能列表。这是订阅兑换站，不是站内名为 Token 代理的路由。
