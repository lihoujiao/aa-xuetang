# 参考学习页的版式与视觉笔记

观察对象以公开可渲染的 `https://www.slashx.cn/courses` 为准。它和 `https://www.slashx.cn/c/learn#course-learning-path` 是同一套「共学空间」：后者多一条左侧图标栏，正文在未登录的浏览器里会被脚本换成登录页；服务端 HTML 里已经有英雄区文案。颜色取自计算样式（2026-11-15，视口 1440×900）。

## 页面分区（自上而下）

1. **顶栏**，高约 65px，吸顶。左：圆角方标 + 字标。中：胶囊导航，当前项有淡紫底。右：语言、金色「加入会员」、紫色「进入工作台」。移动端收成字标、语言、工作台短按钮和菜单。
2. **英雄区**。左文右图。小胶囊眉题，主标题两行，一段说明，两个药丸按钮（实心紫、白底紫字）。右侧是圆桌讨论的插画，背后有很淡的色块。
3. **三条路径**，在英雄区下方排成三列：图标、标题、一行说明。桌面和手机都保持三列。
4. **学习路径** `#course-learning-path`。左下和右下有人物插画探出内容栏。标题右侧是「列表 / 平铺」分段控制。下面按章节堆叠。
5. **章节**。序号色块、标题、稀有度式标签、简介、完成数 `0/n`。课可以是通栏大卡（互动课）或紧凑行（封面、序号、标题、打卡头像、价格、播放）。章节里可插入活动条和讲师行。平铺时行卡变成两列。
6. **打卡榜**，白卡片编号列表。
7. **收束**。左文「今天，从一节课开始。」加回到目录的按钮和四个文字链接；右图是坐着阅读的人。
8. **页脚**。字标、横向文字链、备案与协议。

`/c/learn` 额外有一条约 72px 的左栏：上标、六个图标、通知、头像。当前项左侧有一条紫色指示。营销顶栏不出现在这条工作台壳里。

课程详情是另一套：左 300px 上下的「课程地图」，右上淡紫播放区（标题、简介、时长、登录后观看），右下白卡片复述简介，并有分享。

## 字体与间距

- 全站字体是 **MiSans**。主标题字重约 850，桌面 62px，行高约 1.12，宽度大约 500px。
- 导航 13.5px / 500–600，内边距 8px 12px，圆角 14px。
- 英雄按钮高 45px，全圆角，字重 700。
- 顶栏与内容的桌面内边距大约 24px；章节栏最大宽度明显窄于英雄区（约 720–860px），好让两侧插画露出来。
- 卡片间距大约 10–16px。区块上下留白在 56–96px。

## 交互

- 导航和卡片悬停会轻微变色或上移，阴影变实。
- 「查看课程路线」滚动到 `#course-learning-path`；收束按钮滚回该锚点。
- 「列表 / 平铺」是同一组章节的两种排布，`aria-pressed` 切换。
- 语言按钮在顶栏，不离开当前页。
- 移动端用抽屉菜单；课页三列路径仍保留。
- 未解锁课显示积分和「邀请码兑换」。免费课显示「免费」和播放图标。
- 登录页是全屏风景底上的白卡片：三种继续方式、+86 手机号、验证码、协议勾选、黑色继续。工作台路由的客户端会把地址换成 `/login?callbackUrl=...`。
- 文章页有搜索和四个筛选（全部 / 图文教程 / 活动介绍 / 关于我们）。活动页用状态计数和即将开始 / 往期两组列表。供给页有搜索和类型筛选。

克隆站 AA 学堂沿用这套分区、色值和控件关系，文案、标志和插画都是新的。
